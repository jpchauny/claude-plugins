## Working here

- The specs live under `specs/`. No change is made without a person's approval: the agent shows the whole diff, and the person approves the command that commits and pushes it to `main`. There is no pull request ([LAY-2](https://github.com/jpchauny/claude-plugins/blob/main/apps/indra-software-factory/specs/layers.md#lay-2--people-work-in-layers-0-and-1)).
- Issues opened by layer 3 (inconsistencies found while implementing) are fixed here first ([LAY-5](https://github.com/jpchauny/claude-plugins/blob/main/apps/indra-software-factory/specs/layers.md#lay-5--an-inconsistency-is-fixed-in-layer-1-first)).
