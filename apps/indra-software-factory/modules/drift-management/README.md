# drift-management

The meta module `drift-management` of Indra Software Factory: a drift found
while defining acceptance in layer 3 or implementing in layer 4, sent back to
layer 1, or, when it is a defect of a derived-norms generator, to the
marketplace repository, which holds the plugin of that generator
([LAY-5](../development-methodology/specs/layers.md#rules)).
Its meta use cases are specified in [specs/](specs/module.md).
