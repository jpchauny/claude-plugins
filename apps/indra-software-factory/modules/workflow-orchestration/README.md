# workflow-orchestration

The meta module `workflow-orchestration` of Indra Software Factory: the flow
across the meta modules, from a commit of layer 1 to regenerated norms and derived
norms, to acceptance units and acceptance tests approved by a person, and to
code. Its meta use cases are specified in its meta spec
[specs/](specs/module.md).
