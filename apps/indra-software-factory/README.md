# indra-software-factory

The meta app Indra Software Factory. It is no plugin: each of its meta modules is a
plugin, installed on its own. The meta modules, and where each one is installed,
are in [specs/app.md](specs/app.md). The development methodology, the five
layers and the flow of a run across them, is in the meta module
[development-methodology](modules/development-methodology/README.md).
