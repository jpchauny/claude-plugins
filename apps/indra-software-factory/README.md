# indra-software-factory

The app Indra Software Factory. It is no plugin: each of its modules is a
plugin, installed on its own. The modules, and where each one is installed,
are in [specs/app.md](specs/app.md). The development methodology, the four
layers and the flow of a run across them, is in the module
[development-methodology](modules/development-methodology/README.md).
